# Servify App

This is a small static frontend scaffold for the Servify app included in the sabkuch repository.

Structure

servify-app/
- index.html
- package.json
- src/
  - style.css
  - main.js
  - components/
  - views/

How to run

Install a static server (optional):

npx serve . -s -l 5000

Then open http://localhost:5000/servify-app/
